Feature overview

Cross-platform Azure Service Bus client

Bussin.dev delivers a consistent Service Bus experience across Mac, Linux, and Windows through the browser. No installation, no desktop runtime, and no platform-specific build artifacts.

Open App

Platform-neutral architecture

By using browser-native APIs and AMQP over WebSockets, Bussin.dev avoids the platform compatibility issues of native desktop tools. The same browser experience works across modern browsers and operating systems.

Developer workflows

  • Inspect queues and subscriptions from any workstation
  • Share the same diagnostic workflow across teams
  • Reduce support overhead for platform-specific tooling

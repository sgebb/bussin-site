Browser-Native Features

Bussin is a 100% client-side web application. It runs entirely inside your browser's standard container and communicates directly with your Azure Service Bus namespace. No backend application servers, no credential transit, and no installation required.

Messaging Features

Namespace Discovery

Query Azure Resource Manager (ARM) APIs directly using your login to automatically discover and list your subscriptions, active namespaces, queues, and topics.

Favorites and Folders

Organize your namespaces into custom folders saved securely in your browser's local storage. This is useful for grouping dev, staging, and production environments.

Workspace Switcher

Context-switch between different entities or namespaces quickly. The tabbed workspace lets you switch views without losing your active connection context.

Inline Actions

Stream active and dead-letter message lists, filter payload bodies, and settle message locks (complete, abandon, dead-letter) directly from the grid view.

Direct Connection Security

Because Bussin runs as a static page, it inherits standard browser security protections:

  • Credential Isolation: Microsoft Entra ID logins are handled via the official MSAL.js library. Tokens are held in volatile session memory and never sent to external servers.
  • Same-Origin Protection: Browser security boundaries isolate Bussin's memory space and local configurations from other active web tabs or scripts.
  • Network Transparency: You can inspect every management-plane REST call and WebSocket packet directly in your browser's Network Developer Tools.

Runs Anywhere Instantly

Bussin brings the power of traditional desktop admin tools (like bulk message resubmission, queue moves, and lock renewals) straight to a secure browser tab. It loads quickly, updates automatically, and never requires compilation, native runtimes, or administrator rights.

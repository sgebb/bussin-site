Browser-Native Features

Bussin is a 100% client-side web application. It runs entirely inside your browser's sandboxed container and talks directly to your Azure Service Bus namespace. No backend application servers, no credential transit, and zero installation friction.

Developer Joy & Diagnostic Speed

High-Density Data Grid

Stream and inspect hundreds of active or dead-letter messages inline. Sort by sequence number, filter by custom property keys, and preview JSON or XML payloads instantly without opening multiple modal tabs.

Offline Bookmarks & Folders

Organize numerous namespaces across different Azure subscriptions and tenants into custom nested directories. Your workspace structure and bookmarks are stored safely inside your browser's sandboxed localStorage.

Direct AMQP over WebSockets

Bussin compiles the Rhea AMQP 1.0 messaging library to establish direct data-plane tunnels over WebSockets (Port 443) directly from your machine to Microsoft's gateways. No proxy servers, REST gateways, or intermediary nodes involved.

Zero-Proxy Security Sandbox

Because Bussin runs as a static page served over a global CDN, it inherits robust browser sandbox protections:

  • Credential Isolation: Microsoft Entra ID logins are handled via the official MSAL.js library. Tokens are held in volatile session memory and never sent to external servers.
  • Same-Origin Protections: Standard browser Same-Origin Policy (SOP) boundaries isolate Bussin's memory space and local configurations from other active web tabs or scripts.
  • Network Transparency: Inspect every management-plane REST call and AMQP WebSocket packet directly in your browser's Network Developer Tools. Absolute transparency, zero mystery traffic.

Zero-Install Desktop Parity

Bussin brings the power and safety of traditional desktop admin tools (like bulk message resubmission, live queue moves, and lock renewals) straight to a secure browser tab. It loads in milliseconds, updates automatically, and never requires native compilation, Mono, or administrator rights.

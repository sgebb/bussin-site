Service Bus tooling

Browser-native Azure Service Bus explorer alternative

Bussin.dev is a browser-native alternative to desktop Service Bus Explorer tools. It connects directly with AMQP over WebSockets and supports queue inspection, dead-letter recovery, and topic subscription diagnostics without a desktop install.

Open demo — no login Open app

Why browser-native tooling wins

  • No install: use the app directly in any modern browser.
  • Direct AMQP connection: no backend proxy is required for Service Bus access.
  • Cross-platform consistency: Mac, Linux, and Windows all use the same browser experience.

Core workflows

Queue inspection

Browse queue metadata, runtime counts, and lock details before taking action.

Dead-letter analysis

Inspect and recover dead-lettered messages with explicit controls.

Topic subscriptions

Validate filters, message delivery, and routing for topic-driven systems.

In-browser inspection

Bussin.dev keeps you in the browser while preserving the same messaging semantics as native Service Bus clients.

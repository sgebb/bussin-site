Changelog

What's new in Bussin. The web app updates continuously. Reload app.bussin.dev and you have the latest version; there is nothing to download or upgrade.

Favorite entities, entity filter, and a smoother phone layout

October 29, 2026

Faster ways to get to the queues you actually use, and a round of fixes for phones and smaller screens.

  • Star a queue, topic or subscription to make it a favorite. Favorite entities are listed first in their column and appear under their namespace in the sidebar, one click away from anywhere. See Organizing Favorites
  • New Filter entities box in the explorer header narrows the queue, topic and subscription lists by name. The namespaces page filter now stays at the top of the screen while you scroll
  • The event log only records message operations such as peeks, sends, moves to the dead-letter queue, resubmits, purges and deletes, plus errors. Favoriting and refreshing no longer fill it up
  • Opening a message no longer makes the dialog scroll sideways; long IDs, property values and message bodies wrap instead
  • Refresh keeps its size while it spins, and Refresh Status in User Settings now shows that it is checking
  • On phones, the DLQ toggle moved to the top of the Read panel, after picking the entity, and the entity path line is gone. The message list toolbar is a single row that stays in place while messages scroll, tapping a message opens it, and namespace tiles show only the name and subscription
  • Dropdown menus now use the browser's built-in popovers, so they all close on an outside click or Esc
  • The background gets a seasonal touch: pumpkins in October, Christmas trees in December

Cleaner navigation, Watch, and a simpler phone layout

October 18, 2026

A round of layout and usability changes, mostly aimed at namespaces with many queues and topics, and at using Bussin on a phone.

  • The explorer header is now a single row: a link back to Namespaces, then the namespace and the selected topic, subscription or queue, so you can always see what you are looking at. Favorite, Refresh and Statistics are labeled buttons next to it
  • The queue, topic and subscription lists show four rows and wider cells, so long entity names stay readable. Message counts are shortened (for example 1.2k) so they no longer squeeze the name
  • The arrow on the Peek button opens a menu with Newest first, Watch new messages and Advanced peek. When non-default peek options are active, a line under the button says which ones
  • Live Monitor is now Watch. It only shows messages that arrive after you start it, works on dead-letter queues, and keeps its connection signed in during long sessions
  • New Organize favorites dialog for renaming favorites, creating and deleting folders, and dragging favorites into folders or a new order. Renaming used to be hidden behind a click on the namespace title. When you have no favorites, the sidebar tells you how to add one
  • Add namespace is now the first card on the namespaces page, for connecting with a connection string when a namespace isn't listed
  • On phones Bussin shows a simpler layout focused on peeking, purging and resubmitting dead-lettered messages. See Using Bussin on a phone
  • Fixed: deleting a folder no longer hides the folders inside it, and long entity lists no longer overlap on small screens

Single-step sign-in and consent

October 15, 2026

Signing in now asks for everything Bussin needs in one prompt. Previously you had to approve Azure Management and Service Bus in two separate popups, and the second one could be blocked by the browser.

  • One consent prompt covers both Azure Resource Manager (to list your namespaces) and Azure Service Bus (to peek, send and manage messages)
  • If access is missing or expired, the permissions card offers a single Grant Required Permissions or Sign In Again action that fixes both
  • The permissions card now tells you which problem it found, instead of a generic "Permission Required" message for everything

MCP server for AI assistants

September 2026

Released bussin-mcp, a Model Context Protocol server that connects Claude, ChatGPT, Cursor and other MCP-aware assistants to Azure Service Bus. It shares the AMQP client the web app uses, runs locally, and authenticates with Entra ID.

  • Peek, search and inspect queues, topics, subscriptions and dead-letter queues in natural language
  • Read-only by default; sending and destructive operations are separate opt-in flags
  • --demo mode runs against an in-process simulator, with no Azure account needed

Azure Service Bus

Azure Service Bus is a fully managed enterprise message broker. It supports standard messaging topologies (point-to-point queues and publish-subscribe topics) and communicates natively using the binary AMQP 1.0 wire protocol.

Core Topologies

  • Queues (Point-to-Point): Messages are sent to and stored in a queue. A single consumer retrieves and processes each message, ensuring FIFO (first-in, first-out) order within partitions.
  • Topics and Subscriptions (Publish-Subscribe): Messages are published to a topic, which immediately fans them out to multiple subscriptions. Each subscription acts as an independent virtual queue and can evaluate custom SQL or Correlation filter rules to selectively capture specific messages.

Azure Service Bus vs. Other Brokers

Feature Azure Service Bus AWS SQS and SNS RabbitMQ
Hosting Model Fully managed cloud service (PaaS) Fully managed cloud service (PaaS) Self-hosted or managed service

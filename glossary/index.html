Azure Service Bus

Azure Service Bus is a managed message broker. It supports standard point-to-point queues and publish-subscribe topics, using the binary AMQP 1.0 wire protocol natively.

Core Topologies

  • Queues: Messages are sent to and stored in a queue. A single consumer retrieves and processes each message, ensuring FIFO (first-in, first-out) order.
  • Topics and Subscriptions: Messages are published to a topic, which copies them to multiple subscriptions. Each subscription acts as an independent virtual queue and can use SQL or Correlation filters to selectively capture specific messages.

Glossary

AMQP

AMQP stands for Advanced Message Queuing Protocol. It is the wire protocol used by Azure Service Bus for reliable messaging, and Bussin.dev supports it directly over WebSockets from the browser.

Why AMQP matters for Azure Service Bus

Azure Service Bus uses AMQP to carry message payloads, properties, and delivery semantics. A browser-native client must support AMQP over WebSockets to connect without a native proxy.

Browser-native AMQP over WebSockets

Bussin.dev maintains an AMQP session through the browser by opening a WebSocket connection to Service Bus. This keeps the client simple while preserving the same protocol semantics used by desktop and server-side clients.

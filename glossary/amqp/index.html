Glossary

AMQP

AMQP stands for Advanced Message Queuing Protocol. It is the core wire protocol used by Azure Service Bus, and bussin.dev supports it directly over WebSockets from the browser.

Why AMQP matters for Service Bus

Azure Service Bus uses AMQP to transport message body, properties, and delivery semantics. Supporting this protocol over WebSockets lets a browser client connect directly without a backend mediator.

Browser-native AMQP over WebSockets

bussin.dev maintains AMQP sessions through a secure WebSocket channel so the browser can manage message state and locks directly.

Glossary

Dead-letter queue

A dead-letter queue holds Service Bus messages that could not be processed normally. Bussin.dev exposes dead-letter inspection and recovery without requiring a desktop client.

When messages land in dead-letter queues

Messages are dead-lettered for delivery failures, expiration, filter evaluation issues, or manual moves. The dead-letter queue retains the message body and system metadata for analysis.

Inspecting dead-letter queue details

Look for dead-letter reason, error description, and user-defined properties. This data is essential for diagnosing why a message was rejected or timed out.

How Bussin.dev helps

Bussin.dev lets you open dead-letter queues directly in the browser and move selected messages back to an active queue or subscription. It keeps the workflow explicit so the recovery path is easy to follow.

Message Settlement & Peek-Lock

Managing message locks and settling messages (completing, abandoning, or dead-lettering them) inside the standard Azure Portal can be slow. Bussin provides a fast, direct way to manage message life cycles from your browser.

Azure Portal vs. Bussin

Feature Standard Azure Portal Bussin Web Console
Multi-Message Peeks Slow, single-page peeks with limited sorting options. Fast, responsive data grids. Sort and inspect hundreds of active payloads inline.
Lock Settlement Actions Multiple confirmation dialogs to Complete or Abandon messages. Complete, Abandon, or Dead-Letter multiple selected messages at once.
Custom Dead-Letter Reasons No option to add custom reasons when dead-lettering manually. Provide custom reason and description values on-the-fly.
Lock Lease Management No visibility or warnings for lock expiration times. Active countdown displays with one-click lock extensions (lock renewals).

Message Settlement Actions

Bussin supports standard Service Bus settlement operations:

  • Complete: Confirms successful processing and deletes the message from the queue or subscription.
  • Abandon: Unlocks the message immediately so other consumers can receive it.
  • Dead-Letter: Moves the message to the Dead-Letter Queue (DLQ), allowing you to specify custom error details.

Lease Expiry and Renewals

When you lock messages using Peek-Lock, the broker hides them from other consumers for a set time (default is 30 seconds). If your manual inspection takes longer than this window, the lock expires and the message is released back to active status, which can lead to duplicate processing.

Bussin tracks lock leases and displays a live countdown. If you need more time to inspect a message, a single click extends the lock duration directly from your browser.

Bulk Operations

Bussin supports background bulk operations. You can move thousands of dead-lettered messages back to the main queue or purge backlogs safely while tracking progress with real-time indicators.

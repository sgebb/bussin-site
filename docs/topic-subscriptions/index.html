Workflow guide

Topic subscription inspection

Topic subscriptions route messages to multiple listeners. Bussin.dev exposes subscription filters, delivery metrics, and message previews so you can validate routing behavior without guessing.

View subscription state

Select a topic and open a subscription to inspect active message counts, filter details, and runtime status.

Validate filter behavior

Compare delivered messages against subscription filters to diagnose routing issues or missing traffic.

Inspect dead-lettered subscription messages

Subscription dead-letter queues are included in the workflow, allowing you to pivot directly from subscription state to failed delivery analysis.

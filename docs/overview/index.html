Docs overview

Browser-native Service Bus documentation for real workflows

This overview explains how Bussin.dev supports the core Azure Service Bus scenarios you need in a browser-native tool: peek-lock inspection, dead-letter recovery, and topic subscription diagnostics.

What this documentation covers

  • How to inspect messages without completing them
  • How to review and recover dead-letter queues
  • How to validate topic subscription filters and routing

Typical usage steps

  1. Connect to Azure Service Bus with the browser-native app.
  2. Select the namespace, queue, topic, or subscription to inspect.
  3. Use the peek-lock view to read messages safely.
  4. Open dead-letter queues to review failure details and replay messages.

Screenshots and examples show the intended browser-native workflows and can be updated as the product evolves.

Workflow guide

Dead-letter queue inspection and recovery

Dead-letter queues contain messages that could not be delivered or processed. bussin.dev helps you inspect those messages, understand the failure reason, and move them back into processing when appropriate.

Find dead-letter messages

Select the dead-letter queue from the entity list. The UI highlights dead-letter counts and metadata for quick triage.

Inspect failure details

Open a dead-lettered message to review the reason, error description, and user-defined properties. This gives you the context needed to decide whether to replay or archive the message.

Recover or move messages

Choose a recovery action explicitly: replay to the original queue, move to a different queue, or keep the message in dead-letter for later investigation.

1. Review error metadata
2. Validate payload and headers
3. Choose replay destination or archive

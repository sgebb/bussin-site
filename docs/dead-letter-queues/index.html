Workflow guide

Dead-letter queue inspection and recovery

Dead-letter queues contain messages that could not be processed normally. Bussin.dev helps you inspect those messages and decide whether to replay, fix, or archive them.

Find dead-letter messages

Select the dead-letter queue from the entity list. The UI makes it obvious when a queue has a dead-letter path and how many messages are waiting for review.

This section should contain a screenshot of the dead-letter message list and metadata panels.

Inspect failure details

Open individual dead-letter messages to view failure reason, UserProperties, and system properties. This makes root cause investigation easier than guessing from topic activity alone.

Recover or move messages

Use dedicated actions to move dead-letter messages back to a queue, deliver them to a new subscription, or archive them for later review.

1. Review dead-letter reason and custom properties
2. Validate payload before replay
3. Move message to target queue or keep in dead-letter queue

What is Bussin?

Bussin is a browser-native Azure Service Bus explorer for Azure developers and cloud engineers. It provides direct AMQP WebSocket connectivity so you can inspect queues, subscriptions, and dead-letter queues without a native desktop client.

Problem it solves

Desktop and portal tools can be slow, platform-dependent, or require extra setup. Bussin gives you a fast, browser-first path to inspect Service Bus state and messages.

Who it is for

Azure developers, SREs, and cloud engineers who need direct access to Service Bus queues, topics, subscriptions, and dead-letter workflows.

Why it exists

Because message inspection should not require a local install, Electron app, or backend relay. Bussin keeps the tooling lightweight and browser-native.

Key features

Browse queues and topics

View queue metrics, subscription state, and topic routing in a straightforward browser UI.

Inspect dead-letter queues

Read dead-letter reasons, message headers, and payloads before replaying or archiving them.

Peek-lock workflows

Peek at messages safely, then choose complete, abandon, or replay while preserving lock state.

Cross-platform browser access

Available on Windows, macOS, and Linux in supported browsers without installing a client.

No installation required

Open Bussin in the browser and connect immediately without native setup or runtime dependencies.

Direct Azure Service Bus connection

Connect using AMQP over WebSockets so your browser speaks the same protocol as Service Bus.

Why browser-native matters

Bussin runs as a static browser client and opens AMQP sessions directly to Azure Service Bus. That means no desktop client, no Electron wrapper, and no backend relay to manage.

  • No desktop client or Electron app.
  • No backend proxy required to reach Service Bus.
  • Works from any supported browser on Windows, macOS, or Linux.

FAQ

Does Bussin store my messages?

No. Bussin displays messages in the browser and does not persist them on a backend service.

Do I need a backend?

No. Bussin uses AMQP over WebSockets directly from the browser to Azure Service Bus, so no backend proxy is required.

Is this secure?

Yes. Bussin uses secure WebSockets and Azure Service Bus authentication and avoids extra server-side relays.

Does it work on Mac/Linux?

Yes. The browser-native design works across macOS, Linux, and Windows.

Does it support production Service Bus namespaces?

Yes. Bussin is designed for real Azure Service Bus namespaces and production message inspection workflows.

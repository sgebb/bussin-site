An easy, fast, in-browser Azure Service Bus Explorer

Bussin is a secure, client-side tool for Azure Service Bus that runs entirely in your browser. Log in with Entra ID or connect instantly using a Connection String. Inspect and interact with topics, queues, and subscriptions, allowing you to peek, resubmit, send, and move messages to dead-letter queues. Because your messages and credentials are never sent to an external server or proxy, you maintain full data privacy.

What is Bussin?

Bussin runs entirely in your browser. It establishes WebSockets connections directly to Azure from your browser. This keeps all network traffic strictly client-side and secure, meaning no data is stashed or transited through any third-party server.

Direct Connections

Bussin runs all connections directly in your browser's security sandbox. No backend servers, no intermediate proxy nodes.

Built for Developers

Whether you need to debug live message flows, inspect message bodies, or troubleshoot dead-letter queues, Bussin provides a simple, direct interface.

Private & Secure

Your credentials, access tokens, and message payloads are handled entirely inside your browser and never reach a Bussin server, because there is no Bussin server to reach. See Security for exactly what is kept in browser storage and what is held only in memory.

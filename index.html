bussin
Open App

An easy, fast, in-browser Azure Service Bus Explorer

Bussin is a secure, client-side tool for Azure Service Bus that runs entirely in your browser. It lets you inspect and interact with topics, queues, and subscriptions, allowing you to peek, resubmit, send, and move messages to dead-letter queues. Because your messages and credentials are never sent to a backend proxy or external server, you maintain full data privacy.

Direct Connections, No Backend

Bussin runs entirely in your browser. It compiles a high-performance runtime that pairs with a custom JavaScript connection engine to establish standard WebSockets connections directly to Azure. This keeps all network traffic strictly client-side and secure.

Direct Connections

Traditional web-based clients rely on desktop runtimes or compromise security with backend proxy servers. Bussin resolves this by running all connections directly in your browser's security sandbox.

Built for Developers

Whether you need to debug live message flows, analyze message properties, or perform dead-letter troubleshooting across environments, Bussin provides a simple, direct interface for teams.

Private and Secure

Because your credentials, access tokens, and message payloads are processed purely in client-side memory, your business data never transit a third-party server.

Service Bus Management Features

Metadata & State Browsing

Inspect queues, topics, and subscriptions, including active/dead-letter message counts, active locks, and partition configurations.

Message Search

Search messages by executing client-side pattern matching across message bodies, sequence numbers, session IDs, custom headers, and dead-letter reasons.

Favorites and Folders

Pin favorite namespaces across multiple directory tenants, organize them into folders, and customize UI themes—all stored locally in your browser.

Background Operations

Execute batch actions, including purges or moves, using background services that keep the main user interface fluid and responsive.

Message Workflows

Peek, send, lock, complete, abandon, dead-letter, and resubmit messages. View system and user properties, and resubmit dead-letter messages back to their source.

Direct WebSockets

Connects directly to the Azure Service Bus endpoint over WebSockets, bypassing REST bottlenecks and supporting transactional locks.

Why Run in the Browser?

Running your Service Bus management tools directly in your browser provides several advantages for developers:

  • No Install Required: Avoid local dependency updates, package installations, or local software approvals. Just load the page and connect.
  • Cross-Platform: Achieve identical performance and rendering across Windows, macOS, and Linux.
  • Entra ID Security: Respects your existing Azure roles (such as Data Owner, Receiver, or Sender) using delegated access tokens.
  • Secure: Ephemeral browser memory holds your active session tokens. Nothing is stored on external servers.

Frequently Asked Questions

Does Bussin store or transmit my message data?

No. Bussin operates strictly on a client-side architecture. There are no intermediate servers or backend relays. MSAL.js secures tokens inside your browser sandbox, and the connection engine opens WebSockets directly to Azure. Messages are processed in your browser's memory and never leave it.

Do I need to deploy server components or agents?

No. Bussin runs as a static Single Page Application (SPA). The app can be accessed online or cached locally as a Progressive Web App (PWA).

How does authentication work?

Bussin integrates with Entra ID via PKCE OAuth 2.0. It acquires delegated scopes (specifically user_impersonation), respecting your existing Azure roles. If you do not have permission in Azure, the connection is rejected at the broker level.

Does this support macOS and Linux?

Yes. By utilizing standard browser WebSockets and WebAssembly, Bussin runs on standard browsers across macOS, Linux, and Windows, offering a cross-platform solution to traditional desktop tool fragmentation.
